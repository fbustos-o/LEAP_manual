# Status Bar

**See also:** [Main Menu](Menu.md), [View Bar](../02%20-%20Views/View_Bar.md), [Main Toolbar](Main_Toolbar.md), [Full Screen View](../02%20-%20Views/Full_Screen_View.md)

The status bar is shown at the foot of the main LEAP window.  It shows:

* The LEAP version.
* Information about whether LEAP is fully licensed version, and if so, the name of the person or organization to whom it is licensed.
* The currently open area (e.g. Freedonia).
* The current view (Analysis, Results, Diagram, Energy Balance, etc.)
* The current theme (light, dark, etc.)
* Transient information such as Help hints or calculation status.
