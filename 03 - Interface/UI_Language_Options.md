# Language Translation Options

## Introduction

LEAP supports being used in multiple languages and also includes tools to help you create multi-language versions of your areas (LEAP data). LEAP works with Google Translate to help you semi-automatically translate all of your area data into different languages, including the names of branches, fuels, effects, scenarios, regions, and other types of data. Once you have created these multiple language versions, you can quickly switch among them.  Maintaining multi-language versions can be useful in cases where you want to engage with different stakeholders and want to make your research as accessible as possible.

## Using Language Translation

Language translation options are accessed from the Area: **Language** menu option (![](../assets/images/NewButtons/translate.png)). Under this menu are two sub menus labeled LEAP and Data.

* The **LEAP sub-menu**contains options for translating the LEAP software UI into different languages.  The set of language translations supported includes French, Spanish, Portuguese, Spanish, Chinese, Thai, Indonesian and other languages.  The set of languages is gradually expanding.  Translations have been created using a special translation tool that makes use of Google Translate and input from **volunteers** who review and edit the translations.  We are always interested in creating additional translations.  Please contact SEI if you are willing and able to help create additional language translations.
* The **Data** sub-menu contains options for creating, updating, selecting and deleting language translations of all of your area data including the names of branches, fuels, effects, scenarios, regions, and other types of data. The **create/update** option will create a new language translation of your data and works with Google Translate to automatically translate all of the names of the data in your model.  The Use option lets you quickly switch among different language translations.
