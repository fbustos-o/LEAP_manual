# Main Toolbar

**See also:** [Main Menu](Menu.md), [View Bar](../02%20-%20Views/View_Bar.md), [Status Bar](Status_Bar.md), [Full Screen View](../02%20-%20Views/Full_Screen_View.md)

The main toolbar is used to access the most commonly used functions in LEAP. The options on it are described below. Some of these are hidden in different views.

![](../assets/images/NewButtons/Main%20Toolbar/LEAP-Area.png) [New Area](../16%20-%20Supporting%20Screens/New_Area.md) (Ctrl-N) Creates a new Area. You will be prompted for a name and asked whether you wish to create an area by copying from another, or by starting from a default (blank) set of data.

![](../assets/images/NewButtons/Main%20Toolbar/open.png) Open (Ctrl-O) Opens an existing area.

![](../assets/images/NewButtons/Main%20Toolbar/save.png) Save (Ctrl-S) Saves the current Area, including any data edited in LEAP. This button is only enabled when you have made a change to the data set.

![](../assets/images/NewButtons/Main%20Toolbar/email.png) Email:  Allows you to send your data set to another person.  When using this option LEAP will create a complete copy of the current area as a ".leap" data file and then attach it to an email message.  You will be prompted for the email address of the intended recipient. LEAP supports two different email protocols: SMTP and MAPI.  The former requires no additional software but may sometimes be blocked by firewalls on some networks.  The latter works with standard MAPI software and makes use of a local email client (such as Outlook or Thunderbird) to actually send the email.  See the [Settings](../16%20-%20Supporting%20Screens/Basic_Parameters_Screen.md) screen for more details.

![](../assets/images/NewButtons/Main%20Toolbar/Backup.png) Backup:  Makes a backup copy of the current area as a ".leap" data file.  You will be prompted to select the folder where you wish to create the backup and you will also be asked whether to include any previously saved versions of the area within the ".leap" file.

![](../assets/images/NewButtons/Main%20Toolbar/find.png) Find: Displays the [Find screen](../16%20-%20Supporting%20Screens/Find.md).  Used to help you locate particular branches, fuels or expressions in your data set.

![](../assets/images/NewButtons/Main%20Toolbar/settings.png) Settings: Displays the [Settings](../16%20-%20Supporting%20Screens/Basic_Parameters_Screen.md) screen.  Used to let you view and edit all the settings for your data set and for LEAP itself.

![](../assets/images/NewButtons/tag.png) Tags: Displays the [Tag Manager](../15%20-%20Tagging%20Branches/Manage_Tags.md) screen.  Used to let you edit the tags in your area.

![](../assets/images/NewButtons/Main%20Toolbar/Scenarios.png) Scenarios: Displays the [Manage Scenarios](../16%20-%20Supporting%20Screens/Scenario_Manager.md) screen.  Used to view, create and edit the scenarios in your LEAP data set.  For example, via this screen you can specify how the expressions used to specify data in LEAP are inherited from one scenario to another.

![](../assets/images/NewButtons/fire.png) Fuels (Alt-F)  View or edit the list of [fuels](../16%20-%20Supporting%20Screens/Fuels.md) used in your Area.

![](../assets/images/NewButtons/Main%20Toolbar/Regions.png) Regions (Alt-R)  View and edit the list of [regions](../16%20-%20Supporting%20Screens/Regions.md) in your Area.  This button is only displayed if there is more than one region in the Area.

![](../assets/images/NewButtons/Main%20Toolbar/effects.png) Effects ( Alt-E)  View or edit the list of [effects](../16%20-%20Supporting%20Screens/Effects_Screen.md) for your Area.

![](../assets/images/NewButtons/Main%20Toolbar/units.png) Units (Alt-U)  View or edit the list of [units](../16%20-%20Supporting%20Screens/Units.md) used in your Area.

![](../assets/images/NewButtons/Main%20Toolbar/WhatsThis.png)What's This Help (Shift-F1):  Click this button, then click on any other part of the main screen to get context-sensitive help.
