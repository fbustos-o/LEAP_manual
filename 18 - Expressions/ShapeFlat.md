# ShapeFlat

## Syntax

ShapeFlat

## Description

Used when specifying the shape of the [System Load Shape](../06%20-%20Load%20Shapes/System_Load_Shape.md) or a [Demand Load Shape](../05%20-%20Demand/Load_Shape.md) variable: specifies a flat load shape with equal peak load in each time slice.
