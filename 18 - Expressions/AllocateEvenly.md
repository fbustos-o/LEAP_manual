# AllocateEvenly

**See also:** [Allocate](Allocate.md), [AllocateNone](AllocateNone.md)

## Syntax

AllocateEvenly

## Summary

Allocates the values at a given branch evenly among the map squares within the shape of the current area (in a one region data set) or among the map squares of the shape for the current region (in a multi-region area).

Use in conjunction with the [gridded maps](../02%20-%20Views/Showing_Gridded_Maps_in_Results_View.md) shown in Results View.  This function can only be used in conjunction with the [Geography](../05%20-%20Demand/Geography.md) variable.
