# <> Operator (Not Equal)

## Syntax

Expression <> Expression

See also: [Operators](Operators.md), [IF](If.md), [True](True.md), [False](False.md)

## Summary

The <> operator returns [True](True.md) if the value of the left-hand term is not equal to the right-hand term.  Otherwise it returns [False](False.md).

## Example

IF(3 <> 2, 10, 5) = 10
