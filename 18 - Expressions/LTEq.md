# <= Operator (Less Than or Equal)

## Syntax

Expression <= Expression

See also: [Operators](Operators.md), [IF](If.md), [True](True.md), [False](False.md)

## Summary

The <= operator returns [True](True.md) if the value of the left-hand term is less than or equal to the right-hand term.  Otherwise it returns [False](False.md).

## Example

IF(2 <= 3, 10, 5) = 10
