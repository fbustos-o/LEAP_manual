# ShapeNone

## Syntax

ShapeNone

## Description

Used when specifying the shape of the [System Load Shape](../06%20-%20Load%20Shapes/System_Load_Shape.md) variable or a [Demand Load Shape](../05%20-%20Demand/Load_Shape.md) variable: instructs LEAP to not consider variations among time slices.
