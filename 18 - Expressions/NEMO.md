# NEMO

**See also:**[Introduction to Optimization](../21.2%20-%20Optimization/OptimizationIntroduction.md)

This function is deprecated. It was previously used for controlling which solver should be used when optimizing a scenario.  You can now switch on optimization by simply writing **Yes**.  The [Yes function can also take additional parameters](Yes.md) for finer control over which solver to use, and to enable limited foresight optimization.
