# AllocateNone

**See also:** [Allocate](Allocate.md), [AllocateEvenly](AllocateEvenly.md)

## Syntax

AllocateNone

## Summary

Allocates none of the energy use or emissions at a given branch to the squares on a map associated with the current area or region.

Use in conjunction with the [gridded maps](../02%20-%20Views/Showing_Gridded_Maps_in_Results_View.md) shown in Results View.  This function can only be used in conjunction with the [Geography](../05%20-%20Demand/Geography.md) variable.
