# Non-Energy Sector Properties

See also: [Analysis View](../02%20-%20Views/Data_View.md) , [Non Energy Sector Effect Analysis](Non-Energy_Sector_Analysis.md), [Non Energy Sector Effect Costs](Non_Energy_Sector_Effect_Cost.md)

![](../assets/images/NewScreens/NonEnergyEffectProperties.png)

Use this screen to set the properties of Non Energy Sector Effect branches. Enter a name for a branch and then choose whether the branch represents a category (![](../assets/images/NewButtons/Tree/folder.png)) used only for organizational purposes, or an effect (![](../assets/images/NewButtons/Main%20Toolbar/effects.png)) at which you specify annual total emissions loadings. For effect branches, you should also select the effect. You can select any effect listed in the Area's [effects database](../16%20-%20Supporting%20Screens/Effects_Screen.md). Go to the effects database if you want to define new effects.
