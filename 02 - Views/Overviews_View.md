# Overviews View

Menu Option: View: Overviews  
See also: [View Bar](View_Bar.md) , [Overview Manager](../16%20-%20Supporting%20Screens/Overview_Manager.md), [Scenario Explorer](Scenario_Explorer.md)

![](../assets/images/NewScreens/Overviews1.png)

The Overviews View is used to group together multiple "Favorite" charts (originally created earlier in the [Results View](Results_Screen.md)). With Overviews, you can simultaneously examine different important results, such as costs, environmental impacts, and resource requirements. The Overviews view is only accessible once you have saved one or more favorite charts, and created one or more scenarios.  In addition to displaying charts, the data for those charts is also available in table format by clicking on the Table tab.

You can create multiple named Overviews, each of which can display up to 16 different charts. Use the zoom-in button (**![](../assets/images/NewButtons/zoom-in.png)**) to zoom in on a particular chart, by switching to the [Results View](Results_Screen.md) to display the that chart. Use the Add (**![](../assets/images/NewButtons/Add.png)**) button to add a favorite chart into an Overview or use the Delete (**![](../assets/images/NewButtons/Delete.png)**) button to remove a favorite chart, Use the [Overview Manager](../16%20-%20Supporting%20Screens/Overview_Manager.md) (**![](../assets/images/NewButtons/Views/Overviews.png)**) to select which favorite charts you want to include in an overview. You can also use the Overview manager to add a new overview and to rename and delete overviews.

### The Scenario Explorer

The [Scenario Explorer](Scenario_Explorer.md) is the top panel of the Overviews View.  It can be shown or hidden by clicking the Scenario Explorer button (**![](../assets/images/NewButtons/ScenarioExplorer.png)**) on the Overviews toolbar.  Each color-coded row of the Scenario Explorer corresponds to a particular scenario, while each column corresponds to a particular [Key Parameter](../16%20-%20Supporting%20Screens/Scenario_Template.md).  The Scenario Explorer is designed to let you quickly explore the impact that changing Key Parameters has on the results of your scenarios.

![](../assets/images/NewScreens/ScenarioExplorer.png)

### Formatting Overviews

You can apply a number of formatting options across all charts shown in the Overview. Click on the Y button to toggle the display of Y axes in the charts. Click the Palette (**![](../assets/images/NewButtons/Palette.png)**) button to select a new color palette for all charts in the Overview. Click the Background Image button (**![](../assets/images/NewButtons/Image.png)**) to toggle the display of any background images included in the Favorite charts and click the PowerPoint button (**![](../assets/images/NewButtons/MS-PowerPoint.png)**) to export all of the charts in an Overview to PowerPoint.

When viewing an overview as a table use the toolbar options on the right of the table to adjust the way that numbers are formatted and to adjust the font size and typeface of the table,  Other buttons are available to let you print the table (**![](../assets/images/NewButtons/printer.png)**) and export it to Excel (**![](../assets/images/NewButtons/MS-Excel.png)**).
