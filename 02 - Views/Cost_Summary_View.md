# Summaries View

See also: [View Bar](View_Bar.md)

The summaries view is used to display a variety of specialized types of multi-variable reports that are not otherwise suitable for display in the [Results](Results_Screen.md) and [Energy Balance](Energy_Balance_View.md) views. The four types of reports are:

* [The Cost-Benefit Summary report](Cost_Summary_Report.md)
* [Marginal Abatement Cost Curve (MACC) reports](Marginal_Abatement_Cost_Curve_%28MACC)_Reports.md)
* [Decomposition reports](Decomposition_Summary_Reports.md)
* [User-created reports](User-Created_Summary_Reports.md)

Use the [Manage Summaries](../16%20-%20Supporting%20Screens/Manage_Summaries.md) screen to create and configure named reports of these 4 types.  Each report type can be can be displayed in both chart and table format. Note that one report type, the [cost-benefit summary report](Cost_Summary_Report.md), which summarizes the costs and benefits of scenarios compared to a chosen baseline scenario cannot be deleted.
