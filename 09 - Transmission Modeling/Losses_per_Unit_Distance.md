# Losses (Per Unit Distance)

See also:

Used only when conducting transmission modeling as part of full energy system optimization. Transmission modeling is enabled by editing the Transmission Networks setting in the [Settings: Optimization](../16%20-%20Supporting%20Screens/Basic_Parameters_Screen.md#Optimization) screen.

This variable is specified for each Transmission line (![](../assets/images/NewButtons/line.png)).  Use it to specify the losses per unit distance in power lines (% loss/km compounded over total distance).  Losses can be specified three ways: as [total losses](Losses.md), as losses per unit distance, or as an [efficiency](Efficiency.md).  Use the [module properties](../08%20-%20Transformation/Module_Properties_Wiziard.md) screen to choose how you want to specify transmission losses.

As with other variables used in optimization modeling, this variable is only available for optimized scenarios.  It is not visible in Current Accounts.
