# Max Scrappage Fraction (%)

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Demand Analysis](Demand.md), [Transport Analysis](Transport_Analysis.md),
[Stock
Analysis](Stock_Analysis.md), [Sales](Sales.md), [Stocks](Stocks.md),
[Scrappage](Scrappage.md), [Fraction
of Scrapped Replaced](Fraction_of_Scrapped_Replaced.md)

Used in conjunction with the [Scrappage](Scrappage.md) variable.

The Max Scrappage Fraction specifies
the fraction of vehicles in any one vintage that can be scrapped. By default
it is set to 100% (meaning all vehicles in every vintage can potentially
be scrapped).
