# Lifetime

See also: [Analysis View](../02%20-%20Views/Data_View.md) , [Demand Analysis](Demand.md)

Used only when conducting full energy system optimization modeling and only available at [optimized technology branches](Optimize_Devices.md) (![](../assets/images/NewButtons/Tree/Technology%20Green.png)). Use this variable to specify average expected life of each optimized demand technology in years. Default value is 10 years.
