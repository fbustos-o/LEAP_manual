# Variable OM Cost

See also: [Analysis View](../02%20-%20Views/Data_View.md) , [Demand Analysis](Demand.md)

Used when conducting full energy system optimization modeling and only available at [optimized technology branches](Optimize_Devices.md) (![](../assets/images/NewButtons/Tree/Technology%20Green.png)). Use this variable to specify the annual variable operating and maintenance (O&M) cost per device of each optimized demand technology. Specified in currency units per unit of energy consumed.  Default value is zero.  Variable O&M costs should NOT include fuel costs.  Fuel costs are added automatically during LEAP's optimization calculations.
