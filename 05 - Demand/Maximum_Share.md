# Maximum Share

See also: [Analysis View](../02%20-%20Views/Data_View.md) , [Demand Analysis](Demand.md)

Used only when conducting full energy system optimization modeling and only available at [optimized technology branches](Optimize_Devices.md) (![](../assets/images/NewButtons/Tree/Technology%20Green.png)). Use this constraint variable to specify the maximum share of activity level for each device in any particular year.  Shares must sum to 100% across all devices.  The default value is 100%.

Note - this constraint is not yet operational in LEAP/NEMO.   Coming soon!
