# First Sales Year

See also: [Analysis View](../02%20-%20Views/Data_View.md), [Demand Analysis](Demand.md), [Transport Analysis](Transport_Analysis.md), [Stock Analysis](Stock_Analysis.md), [Sales](Sales.md), [Stocks](Stocks.md)

When conducting a [Transport Analysis](Transport_Analysis.md) or a [Stock Analysis](Stock_Analysis.md) for a demand technology you can specify the first year in which sales data are used to project stocks.  Before this year, stocks are entered as data.  The default value is the base year.
