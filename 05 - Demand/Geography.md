# Geography

See
also: [Analysis View](../02%20-%20Views/Data_View.md), [Environmental
Loadings](Environmental_Analysis.md)

Use the Geography variable
to specify how energy use and emissions at a particular branch are allocated
among the map squares within the shape of the current area (in a one region
data set) or among the map squares of the shape for the current region
(in a multi-region area).  Geographic mappings are set up and named
in the General: [Geographic
Mapping](../16%20-%20Supporting%20Screens/Emission_Mappings.md) screen and results can be viewed on gridded maps shown in
the [Results View](../02%20-%20Views/Results_Screen.md).

This variable must be used
in conjunction with the four special functions that allocate values in
different ways: [Allocate](../18%20-%20Expressions/Allocate.md),
[AllocateEvenly](../18%20-%20Expressions/AllocateEvenly.md),
[AllocateNone](../18%20-%20Expressions/AllocateNone.md) and
[PointSource](../18%20-%20Expressions/PointSource.md).  These
functions can only be used in the Geography variable.
