# Fuels API

See
also: [Automating LEAP with the API](API.md), [Fuels](../16%20-%20Supporting%20Screens/Fuels.md)

The LEAPFuel class represents a Variable for a single Fuel whereas LEAPFuels
is a collection of all Fuels in the area.  The Fuels collection is
a property of the [LEAPApplication](Application.md) class.

Please use the [Script
Editor](Using_the_Script_Editor.md) for documentation of the properties and methods of the Fuels
API. The right-hand pane of the Script editor fully enumerates all collections
and objects in the LEAP API.
