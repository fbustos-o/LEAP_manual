# Regions API

See
also:
[Automating
LEAP with the API](API.md),
[Regions](../16%20-%20Supporting%20Screens/Regions.md)

The LEAPRegion class represents a single LEAP region, whereas LEAPRegions
is the collection of all regions in the active area.  The Regions
collection is also a property of the [LEAPApplication](Application.md)
class.

Please use the [Script
Editor](Using_the_Script_Editor.md) for documentation of the properties and methods of the Regions
API. The right-hand pane of the Script editor fully enumerates all collections
and objects in the LEAP API.
