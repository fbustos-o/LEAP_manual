# Views API

See
also: [View
Bar](../02%20-%20Views/View_Bar.md)

The LEAPView class represents a single LEAP view, whereas LEAPViews
is the collection of all views in the active area. The Views collection
is a property of the [LEAPApplication](Application.md) class.

Please use the [Script
Editor](Using_the_Script_Editor.md) for documentation of the properties and methods of the Views
API. The right-hand pane of the Script editor fully enumerates all collections
and objects in the LEAP API.
