# Favorites API

See
also: [Automating LEAP with
the API](API.md)

The LEAPFavorite class represents a single LEAP favorite, whereas LEAPFavorites
is the collection of all favorites in the active area. The Favorites collection
is a property of the [LEAPApplication](Application.md) class.

Please use the [Script
Editor](Using_the_Script_Editor.md) for documentation of the properties and methods of the Favorites
API. The right-hand pane of the Script editor fully enumerates all collections
and objects in the LEAP API.
