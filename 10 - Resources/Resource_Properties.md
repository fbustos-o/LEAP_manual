# Resource Properties

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Resource Analysis](Resource_Data.md)

Use this screen to set the properties of resource
branches. You can edit the resource type (primary, secondary, wood, biomass,
non energy, etc.) as well specifying whether a resource will be disaggregated
by land type.  This latter option is only available if you have set
up your Settings to include "Land Use Change and Land-based Resources"
on the [Settings](../16%20-%20Supporting%20Screens/Basic_Parameters_Screen.md):
Scope & Scale screen.
