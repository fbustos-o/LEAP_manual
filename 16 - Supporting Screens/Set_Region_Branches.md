# Select Visible Branches

Menu Option: Tree: Select Visible Branches

![](../assets/images/NewScreens/SetVisibleBranches.png)

## Introduction

Use this screen to show or hide tree branches in one or more regions.  This allows you to have different tree structures in each region.  Hidden branches are not included in calculations.  You can only show and hide Demand, Transformation and Key variable branches.  In the demand tree you can show and hide category and technology branches.  In the Transformation tree you can show or hide complete Transformation modules or individual processes.

## Using the Select Visible Branches Screen

* Use the **Next Hidden** button to jump to the next hidden branch.
* Use the **Unhide**All button to make all branches visible in a region.
* Use the **Expand All (**![](../assets/images/NewButtons/tree-expand-all.png)**)**and **Collapse All (****![](../assets/images/NewButtons/tree-collapse-all.png)****)**buttons to fully expand or collapse the tree.
* Use the **Bookmarks** button (****![](../assets/images/NewButtons/bookmark.png)****) to navigate among any bookmarks saved with the tree.

When you click close and return to the Analysis view the tree will show only the visible branches in each particular region. Branches can be made visible again either using this same screen, or by right-clicking on the tree and selecting the Unhide option (****![](../assets/images/NewButtons/Show.png)****).
