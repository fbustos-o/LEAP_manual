# Region Grouping Set Names

See also: [Region Groupings](Region_Groupings.md), [Regions](Regions.md)

![](../assets/images/NewScreens/Rwegion%20Grouping%20Set%20Names.png)

Use the Region Grouping Set Names screen to define up to four different named sets of region groupings.  Leave the names blank if you don't want to define a set.  In the [Region Groupings](Regions.md) screen you can select among these sets, which are used to aggregate results across the regions used in your LEAP area. You can also use these sets in the [Results](../02%20-%20Views/Results_Screen.md) and [Energy Balance](../02%20-%20Views/Energy_Balance_View.md) views for viewing results summed across these sets.
