# Key Parameters

See also: [Overviews View](../02%20-%20Views/Overviews_View.md), [Scenario Explorer](../02%20-%20Views/Scenario_Explorer.md)  
Accessed by: Right-Clicking a Key Parameter in the Overview Screen Scenario Explorer

![](../assets/images/NewScreens/OVKeyParameters.png).

## Introduction

Use the Key Parameters screen to add or edit a Key Parameter for use in the Overviews: [Scenario Explorer](../02%20-%20Views/Scenario_Explorer.md) screen. Each Key Parameter is associated with one branch and variable in your LEAP analysis (and one region in multi-region areas). For each key parameter, you can enter a description of the parameter and set a maximum and minimum value. You can also specify the increment, which is used to calculate the number of steps between the minimum and maximum values when using the slider control in the Scenario Explorer.  LEAP will assign default labels for the minimum and maximum values based on those values and the unit used for the variable. You can override these if you wish.

## Using Key Parameters

You can also specify one or more tags for each key parameter. These can later be used to display a filtered subset of key parameters in the Scenario Explorer. You can add an existing tag by pressing the ![](../assets/images/NewButtons/tag.png) Tag button and selecting ![](../assets/images/NewButtons/Add.png) Add, or delete a tag using the ![](../assets/images/NewButtons/Delete.png) Delete button.
