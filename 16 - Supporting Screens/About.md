# About

Menu Option: Help:About

![](../assets/images/NewScreens/About.png)

Use the About screen to display detailed technical information about LEAP, the currently open area, and your computer.  This includes information about the instance of LEAP you are using, the current area being edited, the version of the windows operating system on your computer, and information about your computer's hardware and network environment.

When [requesting technical support](https://leap.sei.org/default.asp?action=discussion&fid=22) on LEAP, we recommend you copy and paste the information from this screen and share with SEI's staff to help them investigate any issues you are facing.

***Tip:** When reporting on bugs or other issues, please always report the exact version of LEAP you are using (e.g. "2024.1.1.10").*
