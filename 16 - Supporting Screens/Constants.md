# Constants

Menu Option: General: Constants  
See also: [Analysis View](../02%20-%20Views/Data_View.md), [Expressions](../01%20-%20Introduction/Expressions.md), [Examples of Expressions](../02%20-%20Views/Examples_of_Expressions.md), [Expression Builder](../21.6%20-%20Wizards%20and%20Properties/Expression_Builder.md)

![](../assets/images/NewScreens/Constants.png)In addition to referencing variables (values that can change over time and between scenarios), your expressions can also reference the values of constants (including your own user-defined constants). A default set of constants are included that define various molecular weight constants. These are particularly useful in defining emission factors.

Use the Constants screen to view and edit the names and values of constants. Use the ![](../assets/images/NewButtons/Add.png) and ![](../assets/images/NewButtons/Delete.png) buttons to add and deleted constants, and use the ![](../assets/images/NewButtons/Decimal-increase.png) and ![](../assets/images/NewButtons/Decimal-decrease.png) buttons to change the number of decimal places displayed on screen. Note that the basic molecular weight constants are locked and cannot be deleted.
