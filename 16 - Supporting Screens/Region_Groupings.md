# Region Groupings

Menu Option: General: Region Groupings  
See Also: [Regions](Regions.md), [Region Grouping Names](Region_Grouping_Names.md)

![](../assets/images/NewScreens/RegionGroups.png)

**Note:** This screen is only available when your area has more than one region.

## Introduction

The Region Groupings screen lets you specify groups of [regions](Regions.md) for reporting purposes in the [Energy Balance](../02%20-%20Views/Energy_Balance_View.md) and [Results](../02%20-%20Views/Results_Screen.md) views.  So for example, if you create a global analysis, you could specify each region as a country and then specify regional groupings for Europe, North America, Africa, Latin America, Asia, etc.

## Using the Region Groupings Screen

Use the Add (![](../assets/images/NewButtons/Add.png)) button to add a new grouping and the Delete button (**![](../assets/images/NewButtons/Delete.png)**) to delete a grouping. Note that you will not be allowed to delete any groupings currently assigned to a region in your Area. You can also reorder the list using the Up (**![](../assets/images/NewButtons/Arrow-up.png)**) and Down (**![](../assets/images/NewButtons/Arrow-down.png)**) buttons.

You can specify up to four different sets of Region Groupings.  Use the [Set Names](Region_Grouping_Names.md) button at the top of the screen to define these sets of named groupings.  Use the Set selection box at the top of the screen to select among these sets.
