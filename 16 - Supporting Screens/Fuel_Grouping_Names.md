# Fuel Grouping Set Names

See also: [Fuels](Fuels.md), [Fuel Groupings](Balance_Catagories.md)

![](../assets/images/NewScreens/FuelGroupSets.png)

## Introduction

The Fuel Groupings Set Names screen is used to define the names of up to 4 different sets of fuel grouping.  These grouping can later be used when showing results in the Results and Energy Balance Views

## Using the Fuel Grouping Set Names Screen

Leave the names blank if you don't want to define a set.  In the [Fuel Groupings](Balance_Catagories.md) screen you can select among these sets, which are used to aggregate results across the detailed fuels used in your LEAP area. You can also use these sets in the [Results](../02%20-%20Views/Results_Screen.md) and [Energy Balance](../02%20-%20Views/Energy_Balance_View.md) views for viewing results summed across these sets.
