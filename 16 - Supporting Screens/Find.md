# Find

Menu Option: Edit: Find

![](../assets/images/NewScreens/Find.png)

## Introduction

Use the Find tool (F3) to find information **within your area** or **within the LEAP web site**. The results of searches are displayed as rows in a table in the lower part of the screen. Find is a modal window, which stays on top of the main window, so you can keep it open even if you return to work on the main screen. 

## Searching within an area (branches, expressions, fuels, & notes)

Within your area you can search for branches by name of by ID, or for text within expressions or notes. You can also search for the branches where different fuels are used. Double-click within the results and LEAP's will jump to selected branch, variable, scenario and region in [Analysis View](../02%20-%20Views/Data_View.md).

When searching branches and notes searches can be case sensitive and you can search for whole words or parts of words. When searching for expressions, you can filter the displayed results by variable, scenario, and region (in a multi-region data set).

When searching expressions you can either show results only within expressions that were explicitly entered, or you can also include results within inherited expressions.

To help with model debugging, the Find tool can also highlight expression errors, and you can choose to filter the results to show only those branch/variables with errors.

## Searching the LEAP web site

Select Search: **LEAP web site** to have Find search online for information in LEAP's help system, support forums, publications, workshops and applications. For these online resources, Find will show you a preview of the pages it finds. You can open those pages by double-clicking on the search result records.

Online search accepts multiple keywords which can be connected using AND & OR operators. 

Searches of the support forum use short AI-generated summaries of the discussions in each thread. These AI summaries are also displayed on the LEAP website support forums.
