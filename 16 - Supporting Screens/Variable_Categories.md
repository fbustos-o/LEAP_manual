# Variable Categories

Menu Option: Analysis: Variables: Variable Categories  
See also: [Analysis View](../02%20-%20Views/Data_View.md) , [Key Assumptions](../21.6%20-%20Wizards%20and%20Properties/Macrovariable_Properties_Wizard.md), [Indicators](../14%20-%20Indicators/Indicators.md), [User Variables](User_Variables.md)

Use this screen to view,edit and reorder the list of variable categories.  You can also select a color for each category.  The tabs of all variables in a given category are displayed using this color.  LEAP's built-in variables are pre-assigned to a default set of categories (with gray tabs).  You cannot change these categories, nor can you alter the category color.
