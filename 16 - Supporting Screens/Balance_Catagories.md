# Fuel Groupings

Menu Option: General: Fuel Groupings  
See also: [Fuels](Fuels.md), [Fuel Grouping Names](Fuel_Grouping_Names.md)

![](../assets/images/NewScreens/FuelGroups.png)

## Introduction

When producing energy balances and other reports, it is sometimes useful to be able to show results aggregated across types of fuels (for example, showing all oil products rather than each individual product). To allow for this, LEAP lets you assign a grouping to each fuel.

## Using the Fuel Groupings Screen

Use the Add (![](../assets/images/NewButtons/Add.png)) button to add a new grouping and the Delete button (**![](../assets/images/NewButtons/Delete.png)**) to delete a grouping. Note that you will not be allowed to delete any groupings currently assigned to a fuel in your Area. You can also reorder the list using the Up (**![](../assets/images/NewButtons/Arrow-up.png)**) and Down (**![](../assets/images/NewButtons/Arrow-down.png)**) buttons.

You can specify up to four different named sets of fuel groupings.  Use the [Set Names](Fuel_Grouping_Names.md) button at the top of the screen to define these named sets.  Use Set selection box at the top of the screen to select among these sets. Use the Export to Excel (**![](../assets/images/NewButtons/MS-Excel.png)**) button to export the groupings to an Excel spreadsheet.
