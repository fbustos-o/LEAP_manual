# Manage Overviews

See Also [Overviews View](../02%20-%20Views/Overviews_View.md)

![](../assets/images/NewScreens/ManageOverviews.png)

## Introduction

Use the Manage Overviews screen to edit the set of charts and tables displayed in the Overviews view.

## Using the Manage Overviews Screen

The Manage Overviews screen is accessed from the [Overviews View](../02%20-%20Views/Overviews_View.md) toolbar. Use it to add  (![](../assets/images/NewButtons/Add.png)), delete (![](../assets/images/NewButtons/Delete.png)) and rename (![](../assets/images/NewButtons/rename.png)) overviews. You can create as many Overviews as you wish. Use the Overview selection box to select which overview you wish to manage, and then use the two panes in the bottom part of the screen to select and organize the favorite charts to be included in each Overview. When you click the close button, the edited overviews will be displayed on screen in the Overviews view. For any given Overview you can select the favorites to be included using the two pane display.  The pane on the left lists All Favorite charts, while the one on the right shows the favorites currently included in the selected Overview.  
  
A toolbar between the two panes is used to add  (![](../assets/images/NewButtons/Play.png)) and remove (![](../assets/images/NewButtons/PlayReverse.png))  favorites or add all (![](../assets/images/NewButtons/Play-forward.png)) or remove all (![](../assets/images/NewButtons/Play-backward.png)) favorites. Use the up (![](../assets/images/NewButtons/Arrow-up.png)) and down (![](../assets/images/NewButtons/Arrow-down.png)) buttons to change the display order of the favorites in the selected Overview.  Favorites are displayed in order from left to right and from top to bottom in the Overviews view.  Use the delete button (![](../assets/images/NewButtons/Delete%20V2.png)) to delete a favorite from the All Favorites list.  This will also delete the favorite from any other overviews that use it.  Deleting favorites only erases chart settings it does not delete any data or results.
