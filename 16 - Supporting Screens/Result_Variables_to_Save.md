# Results to Save

Menu Option: General: Results to Save

![](../assets/images/NewScreens/ResultstoSave.png)

To further assist in reducing calculation times, you can use the Results to Save screen to selectively choose which Results should or should not be saved.  Use the check boxes to mark which results will be saved.  Any left unchecked will not be available in the Results view.  A toolbar at the top of the screen let's you quickly expand or collapse the tree display. Reducing the number of checked options will reduce LEAP's calculation time.

This screen can also be accessed from within the General: [Settings](Basic_Parameters_Screen.md): Scope screen.
