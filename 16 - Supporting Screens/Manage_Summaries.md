# Manage Summaries

See also: [Summaries View](../02%20-%20Views/Cost_Summary_View.md)

Accessed from main tool bar in [Cost-Benefit Reports,](../02%20-%20Views/Cost_Summary_Report.md) [Decomposition Reports](../02%20-%20Views/Decomposition_Summary_Reports.md), [MACC Reports](../02%20-%20Views/Marginal_Abatement_Cost_Curve_%28MACC)_Reports.md), [Affordability Reports](../02%20-%20Views/Affordability_Reports.md), and [User Summary Reports](../02%20-%20Views/User-Created_Summary_Reports.md).

![](../assets/images/NewScreens/ManageSummaries.png)

## Introduction

The Manage Summaries screen is used to add, delete and rename reports.

## Using the Manage Summaries Screen.

Use the Add button (![](../assets/images/NewButtons/Add.png)) to add a new summary report (you will be prompted for a name and type). Use the Delete button (![](../assets/images/NewButtons/Delete.png)) to delete a summary report. You can also rename reports (![](../assets/images/NewButtons/Properties.png))  or use the duplicate button (![](../assets/images/NewButtons/Copy.png)) to make a copy of an existing named summary report.
