# Units

Menu Option: General: Units (also shown on the [main toolbar](../03%20-%20Interface/Main_Toolbar.md))

![](../assets/images/NewScreens/Units.png)

## Introduction

This screen provides access to the all the measurement units used in LEAP. LEAP makes use of a wide range of units for most classes of data, including data denominated by energy, power, mass, volume, length and currency units. The default units database provided with LEAP should suffice for most analyses. In rare circumstances you may wish to edit some of the unit conversion definitions in LEAP, or add your own units. Most commonly you may wish to add to or update the currency units stored in LEAP, or add additional units to the "Other Units" list for use with the [Activity Level](../05%20-%20Demand/Activity_Level.md) data in your Demand analysis.

## Using the Units Screen

Click on the Units Class selection box to display different classes of units (mass, volume, energy, power, area, length, currency, and "other"). Use the Add (![](../assets/images/NewButtons/Add.png)) button to add a new unit and the Delete button (![](../assets/images/NewButtons/Delete.png)) to delete a unit. Use the rename button (![](../assets/images/NewButtons/rename.png)) to change a unit's name. To avoid errors, the most common units cannot be changed. Use the ![](../assets/images/NewButtons/Decimal-increase.png)  and ![](../assets/images/NewButtons/Decimal-decrease.png) buttons to increase or decrease the number of decimal places displayed or use the ![](../assets/images/NewButtons/Scientific.png) button to show values in scientific format.

The last class of units labled "Other Units" do not have conversion factors associated with them, since they are never converted to other units of a similar class. These units are only used in specifying [Activity Level](../05%20-%20Demand/Activity_Level.md) data.

The Default Units screen (![](../assets/images/NewButtons/units.png)) is used to set default energy, distance, currency and fuel economy units, used when adding new branches to the tree.
