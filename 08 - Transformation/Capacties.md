# Exogenous Capacity

See also: [Analysis View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md), [Endogenous Capacity](Endogenous_Capacity.md), [Specifying Capacity Data](Specifying_Capacty_Data_in_LEAP.md)

Note: Capacity data can only be entered for a module if it is first you specified on the [Module Properties](Module_Properties_Wiziard.md) screen.

Exogenous Capacity values are used to reflect existing capacity as well as planned/committed capacity additions and retirements. Notice that in all years you need to specify total capacity, not additions and retirements.  For more information see: [Specifying Capacity Data](Specifying_Capacty_Data_in_LEAP.md).

You can use the [Time Series Wizard](../21.6%20-%20Wizards%20and%20Properties/Time_Series_Wizard.md) to specify a [Step](../18%20-%20Expressions/Step.md) function that lists the capacity values in any year when an addition or retirement takes place.
