# Module Costs

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md)

Note: Cost
data is shown only if the Cost
check box is checked in the [Module Properties](Module_Properties_Wiziard.md) screen and if costs
are enabled on the Scope tab of the [Settings](../16%20-%20Supporting%20Screens/Basic_Parameters_Screen.md) screen.

Use the Module costs variable to specify costs for a whole module that
do not vary by process or per unit of capacity or energy consumed. Module
costs can be useful for specifying one-time expenses such as a program
to reduce to reduce the system load factor, or to reduce transmission
and distribution losses.
