# Fuel Source

See also: [Analysis View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md)

Used only when conducting full energy system optimization modeling.  Used to indicate the source module for a feedstock fuel. By default is set to [SourceBelow](../18%20-%20Expressions/SourceBelow.md), meaning the fuel is produced in a lower down Transformation module.  You can also use the [SourceModule](../18%20-%20Expressions/Source_Module.md) expression to indicate that the fuel comes from a particular (named) Transformation module.
