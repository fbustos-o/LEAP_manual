# Renewable Qualified

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md),
[Renewable Target](Renewable_Target.md)

This variable, used in conjunction with the [Renewable
Target](Renewable_Target.md) variable set at the module level in optimization scenarios
is used to specify the percentage of the output of the process that qualifies
as renewable from 0% to 100%. Only applicable in optimization-based scenarios.

Take care: it is possible to
mark any process as being renewable regardless of what feedstock fuel
it actually uses.  Normally you would want to mark wind, solar, hydro,
biomass, etc. as being renewable qualified.  However, in some situations
hydro, and biomass projects may not qualify for an RPS.
