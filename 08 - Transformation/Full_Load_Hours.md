# Full Load Hours

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md),
[Specifying Capacity Data](Specifying_Capacty_Data_in_LEAP.md),
[Module Properties](Module_Properties_Wiziard.md)

This variable is only relevant for energy storage processes. It is a
message of the storage capacity of the process and specifies the number
of hours an energy storage process can be used at full load after it is
fully charged.

Note: energy storage modeling is only supported when using LEAP with
NEMO optimization calculations.
