# Output Fuel Properties

See
also: [Analysis
View](../02%20-%20Views/Data_View.md), [Transformation Analysis](Transformation.md)

Use the Output Fuels Properties screen to select the fuel produced by
the module. There are no particular limits on the number of output fuels
from each module. Notice though that all processes in a module produce
the same set of output fuels, and each processA Transformation branch that describes an individual technology or group of technologies within a module such as a particular electric plant or oil refinery
produces those fuels in the same proportions.
