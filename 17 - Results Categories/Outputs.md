# Outputs (Generation)

See also: [Results View](../02%20-%20Views/Results_Screen.md)  
Result Type: Transformation

This result displays the annual energy produced by a given Transformation module.  In the case of an electric generation module, this corresponds to the annual amount generated.  Results can be shown organized by branch, scenario, year, fuel and region (in multi-regional areas).  In addition you can divide result by output type, showing primary products only, co-products only, or all outputs.

There are two variations of this result variable:

* Outputs by Output Fuel shows outputs organized by the list of output fuels
* Outputs by Feedstock Fuel shows outputs organized by the list of feedstock fuels.
