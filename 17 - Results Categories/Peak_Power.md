# Peak Power Requirements

See
also: [Results
View](../02%20-%20Views/Results_Screen.md)  
Result Type: Transformation

This results category shows the peak load on a given module in a year
across all time slices. This variable is generally only relevant for electricity
generation modules and is shown in megawatts or another power unit. This
variable is only reported if you have specified capacity data for the
module.  Results can be shown organized by branch, scenario, year
and region (in multi-regional areas).

Peak load is calculated based on the requirements
for electricity and the module load factor (which itself is based on the
shape of  the load curve). Electricity requirements are calculated
based on your energy demand analysis and any upstream electricity losses
(for example in a Transmission and Distribution module).
