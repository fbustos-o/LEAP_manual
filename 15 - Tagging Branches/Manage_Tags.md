# Tags (Alt+T)

See also: [Tagging Branches](Tagging_Branches.md), [Tag Groups](Tag_Groups.md)

![](../assets/images/NewScreens/Tags.png)

## Introduction

Use the Tags screen (![](../assets/images/NewButtons/tag.png)) to view, edit and organize the tags for a LEAP area.  Tags can be used for color coding tree branches, for filtering and displaying [results](../02%20-%20Views/Results_Screen.md), and for controlling the visibility of [user-defined variables](../16%20-%20Supporting%20Screens/User_Variables.md).  You can also use this screen to organize your tags into groups: useful for organizing and displaying how results are viewed.

## Using the Tags Screen

Click on a tag to edit its name, while at the foot of the screen you can enter a longer description.  Use the Add (![](../assets/images/NewButtons/Add.png)) button to add a tag and the Delete button (![](../assets/images/NewButtons/Delete.png)) to delete a tag.

The Tagged Branches column shows you how many branches in the main LEAP [Tree](../03%20-%20Interface/TreeOverview.md) have been tagged with each tag.

Use the Group selection box in the tool bar to filter the screen to show all tags or any one group of tags.  When showing one group of tags you can also reorder tags using the Up (![](../assets/images/NewButtons/Arrow-up.png)) and Down (![](../assets/images/NewButtons/Arrow-down.png)) buttons.  Click on the column titles to sort the tags by name or tag order.  Note that reordering of tags is only available when tags are displayed in order.

Use the Add Group (![](../assets/images/NewButtons/Add.png)) button to add a tag group and the Delete Group button (![](../assets/images/NewButtons/Delete.png)) to delete a group. When selecting or deleting a group, LEAP will show you the number of tags associated with each group in parentheses. You can also access the separate [Tag Groups](Tag_Groups.md) screen to manage groups of tags.

Click the ditto button (![](../assets/images/NewButtons/Ditto.png)) to duplicate a field value from the value immediately above it.  The tool bar also gives you access to the standard, copy, cut, and paste clipboard options.

Click the ![](../assets/images/NewButtons/MS-Excel.png) button to export the tags and their group names to Excel.  Note that in Analysis View you can separately export and import the lists of tags associated with each tree branch.
