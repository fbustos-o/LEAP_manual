# Tag Groups

See also: [Tagging Branches](Tagging_Branches.md), [Tags](Manage_Tags.md)

## Introduction

Use the Tag Groups screen (![](../assets/images/NewButtons/tag.png)) to view, edit and organize groups of tags in a LEAP area.  For example. you can make groups denoting policies, sectors, power plant technologies, etc.  Use this screen to specify named groups of tags and specify which groups will be used as an extra dimension for displaying results in the charts and tables shown in [Results View](../02%20-%20Views/Results_Screen.md).

## Using the Tag Groups Screen

Click on a tag group to edit its name, while at the foot of the screen you can enter a longer description.

The Number of Tags column shows you how many tags are in each group.

Use the Add (![](../assets/images/NewButtons/Add.png)) button to add a group and the Delete button (![](../assets/images/NewButtons/Delete.png)) to delete a group.  Use the Up (![](../assets/images/NewButtons/Arrow-up.png)) and Down (![](../assets/images/NewButtons/Arrow-down.png)) buttons to reorder groups.

If you want to use tags as an optional dimension in the Results View screen, then put a check in the Use For Results column. When using tags for viewing results, each branch must only be tagged with a single tag from any one tag group.  Once you have created tags at different branches, you can use Tags as an additional dimension in your [Results View](../02%20-%20Views/Results_Screen.md) charts and tables.
